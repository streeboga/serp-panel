# Domains Rework — объединение доменов, конкурентов и страниц

**Дата:** 2026-03-27
**Статус:** Draft

## Суть

Разделы "Домены" и "Конкуренты" объединяются. Домен — центральная сущность для мониторинга (свой и чужой). Страницы (Pages) переносятся внутрь домена. Добавляется индексация — запрос `site:domain.com` через парсер.

## Изменения модели

### Domain (расширение)

Новые поля:
- `parent_id` (FK→domains, nullable) — родительский домен (для поддоменов/сателлитов)
- `type` enum: own, competitor, satellite — тип домена
- `tags` — spatie/laravel-tags (HasTags trait)
- `indexed_pages_count` (int, nullable) — кол-во проиндексированных страниц

### Pages → привязка к Domain

`pages.domain_id` уже есть. Теперь это обязательная привязка — каждая page принадлежит домену.

### Индексация (новая фича)

Запрос `site:domain.com` через XMLRiver → получаем список страниц домена из поисковика.

Новая таблица:
```sql
domain_index_results (
  id, domain_id, url, title, description, snippet_links (jsonb),
  position, collected_at, engine, created_at
)
```

Новый Job: `IndexDomainJob` — запрос `site:domain.com` через XMLRiver, парсинг результатов, сохранение.

### Удаление раздела "Конкуренты"

Конкуренты → это просто домены с `type=competitor`. Вся логика конкурентов переезжает в Domains.

## Фронтенд

### /projects/{id}/domains — расширенная таблица

Столбцы:
- Домен (ссылка внутрь)
- Тип (Свой / Конкурент / Сателлит) — бейдж
- Родительский домен
- Теги
- Страниц (count pages)
- TOP-3 / TOP-10 / TOP-100 (из SERP данных)
- Индекс (indexed_pages_count)
- Действия (индексация, редактирование, удаление)

### /projects/{id}/domains/{domainId} — страница домена

Табы:
- **Обзор** — статистика: TOP-3/10/100, кол-во страниц, индекс
- **Страницы** — таблица pages этого домена (перенос из /pages с фильтром по domain)
- **Индекс** — результаты `site:` запроса: URL, заголовок, описание, snippet_links, позиция
- **Ключевые слова** — ключи привязанные к страницам этого домена

### Навигация

- Убрать таб "Конкуренты" из project navigation
- "Страницы" таб убрать (переезжает внутрь домена)
- "Домены" остаётся, внутри — всё

## Приоритеты реализации

1. Backend: расширить Domain модель (parent_id, type, tags)
2. Backend: IndexDomainJob + domain_index_results
3. Frontend: расширить таблицу доменов
4. Frontend: страница домена с табами
5. Frontend: перенос Pages внутрь домена
6. Frontend: убрать Конкуренты таб
