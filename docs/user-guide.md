## Первый запуск

### Установка
```bash
# Клонировать, настроить .env (БД, Redis)
composer install
php artisan migrate:fresh --seed

# Тестовый аккаунт:
# Email:    admin@serp.test
# Пароль:   password

cd frontend && npm install && npm run dev
# Открыть http://localhost:5174
```

### Что создаёт сидер
- 2 организации (SEO Agency Pro + Freelance Projects)
- 2 проекта с доменами, категориями, кластерами
- 23 ключевых слова с 14 днями SERP данных
- 10 правил классификации
- XMLRiver парсер с настроенными credentials

## Организации и роли

### Создание организации
Организация создаётся автоматически при регистрации. Название можно изменить в **Настройки → Организация → Редактировать**.

### Переключение между организациями
Если у вас несколько организаций — dropdown в верхнем левом углу сайдбара.

### Роли
| Роль | Что может |
|------|----------|
| **Admin** | Всё: управление организацией, участниками, биллингом |
| **Manager** | Проекты, ключи, парсеры, расписания, классификация |
| **Analyst** | Просмотр всех данных + экспорт |
| **Viewer** | Только просмотр |

### Приглашение участников
**Настройки → Участники** → ввести email + выбрать роль → Пригласить.

## Проекты и домены

### Создать проект
**Проекты → Новый проект** → название + описание.

### Добавить домены
В проекте → вкладка **Домены → Добавить домен**:
- **Свой домен** (is_own = true) — ваш сайт, для которого отслеживаются позиции. Отмечается зелёным в таблицах.
- **Конкуренты** — домены для сравнения.

> Важно: должен быть хотя бы один "свой" домен — он используется для определения позиций в таблице мониторинга.

## Категории и кластеры

Вкладка **Категории** в проекте.

**Категории** — верхний уровень группировки (например: Электроника, Одежда, Услуги).

**Кластеры** — подгруппы внутри категории (например: Смартфоны, Ноутбуки внутри Электроники).

Каждый ключевик привязан к кластеру. Кластеры нужны для:
- Группировки в таблице мониторинга
- Фильтрации по категории/кластеру
- Указания при импорте ключей

### Создание
1. **Добавить категорию** → ввести название
2. В карточке категории нажать **+ Cluster** → ввести название кластера

## Импорт ключевых слов

Вкладка **Ключевые слова → Импортировать**.

### Формат ввода
Один ключ на строку:
```
купить смартфон
ноутбук для работы
iphone 16 pro
```

Или CSV с указанием кластера:
```
купить смартфон;Смартфоны
ноутбук для работы;Ноутбуки
```

### Параметры импорта
- **Кластер** — в какой кластер добавить (если не указан в CSV)
- **Регионы** — чекбоксы, можно выбрать несколько (Москва, СПб, и т.д.)
- **Поисковик** — чекбоксы Google / Яндекс (можно оба сразу)
- **Устройство** — чекбоксы Desktop / Mobile

> При выборе Google + Yandex + Desktop + Mobile — каждый ключ создастся 4 раза (для всех комбинаций). Это нормально — каждая комбинация мониторится отдельно.

## Подключение парсеров

**Парсеры → Добавить парсер**

### XMLRiver (рекомендуется)
- Тип: **XMLRiver (Яндекс + Google)**
- Base URL: `http://xmlriver.com/search/xml`
- Engines: google, yandex
- Нужны: User ID и API Key с xmlriver.com
- Поддерживает и Яндекс, и Google

### Яндекс XML (прямой)
- Тип: **Яндекс XML (прямой)**
- Base URL: `https://yandex.ru/search/xml`
- Нужны: логин и ключ с yandex.ru/search/xml
- Только Яндекс

### Webhook / API
- Тип: **Webhook / API (входящий)**
- Внешний сервис отправляет данные на `POST /api/v1/webhooks/serp`
- Нужен: webhook_secret (задаёте сами)
- Любой поисковик

### Тестирование
Кнопка **Тест** проверяет подключение к парсеру.

## Настройка расписаний SERP

**Расписания → Добавить расписание**

1. Выбрать **проект** — будут собираться данные для всех ключей проекта
2. Выбрать **парсер** — XMLRiver, Яндекс XML или Webhook
3. Выбрать **частоту** — ежедневно / раз в 3 дня / еженедельно / раз в 2 недели / ежемесячно

> Поисковик и устройство берутся из настроек каждого ключевика (указанных при импорте).

### Запуск вручную
Кнопка **Запустить** немедленно создаёт задачи в очереди для всех ключей проекта.

### Статус
- **Вкл** / **Выкл** — клик переключает
- **Последний запуск** / **Следующий запуск** — автоматически обновляются

## Таблица мониторинга

Главная таблица на вкладке **Ключевые слова** проекта.

### Структура
| Элемент | Описание |
|---------|----------|
| 🔗 иконка | Ссылка на наш URL (target=_blank) |
| Ключевик | Название + категория/кластер подписью |
| ! «» ~ | Частотность: точная / фразовая / широкая |
| Даты (26.03, 25.03...) | Позиции по дням, G = Google, Я = Yandex |
| Зелёное число | Улучшение (+3 = поднялись на 3 позиции) |
| Красное число | Ухудшение (-5 = упали на 5 позиций) |

### Период
Выбор: 7 / 14 / 30 дней.

## Фильтры, группировки и пресеты

### Фильтры (мультивыбор)
Каждый фильтр — dropdown с чекбоксами:
- **Поисковик** — Google / Yandex
- **Устройство** — Desktop / Mobile
- **Категория** — по категориям проекта
- **Кластер** — по кластерам
- **Регион** — по регионам

"Все" = нет фильтра. Снимите галку с одного — покажутся все остальные.

### Группировка
Dropdown **Группировка** — чекбоксы:
- Категория, Кластер, Поисковик, Устройство, Регион
- Можно несколько одновременно (Категория + Регион)
- Каждая группа сворачивается/разворачивается кликом

### Сортировка
Клик по заголовку столбца:
- **Ключевик** — алфавит ↑↓
- **!** — по точной частотности ↑↓
- **«»** — по фразовой ↑↓
- **~** — по широкой ↑↓
- **Первая дата** — по позиции ↑↓

### Пресеты
**Сохранить пресет** — сохраняет текущие фильтры + группировку + сортировку + период.
**Пресеты** → выбрать сохранённый — восстанавливает все настройки.

### Массовые операции
Отметьте чекбоксы → появятся кнопки:
- **Переместить** — в другой кластер
- **Удалить** — массовое удаление

## Детальная страница запроса

Клик по ключевику → страница с табами:

### SERP
Таблица поисковой выдачи: позиция, домен, тип сайта, заголовок, URL.
Фильтр по дате и TOP-N (10/20/50/100).

### История
**График позиций по дням** (ось Y инвертирована — 1 вверху).
Таблица: дата, позиция, URL.

### Вордстат
3 числа частотности: точное, широкое, фразовое.
**График трендов** помесячно (если есть данные).

### Подсказки
Связанные запросы из Яндекс Wordstat.

## Wordstat (частотность)

### Расписания Wordstat
**Расписания Вордстат → Добавить расписание**:
- Выбрать проект
- Частота сбора
- Чекбоксы: собирать тренды / собирать подсказки

### Данные
3 типа частотности:
- **!** (exact) — точное вхождение "купить смартфон"
- **«»** (phrase) — фразовое "купить смартфон" + словоформы
- **~** (broad) — широкое, все варианты

### Подключение Яндекс API
Для реального сбора нужен OAuth токен:
**Настройки → Подключения → Добавить → Яндекс**

## Классификация доменов

Автоматическая разметка доменов в SERP по типам сайтов.

### Типы
Маркетплейс, Интернет-магазин, Агрегатор, Информационный, Блог, Лендинг, Гос.сайт.

### Правила
**Классификация → Добавить правило**:
- **Тип правила**: domain_exact, domain_contains, domain_regex, url_regex, title_contains
- **Паттерн**: `ozon`, `wildberries`, `.*marketplace.*`
- **Тип сайта**: выбрать из списка
- **Приоритет**: чем выше число, тем раньше применяется

### Системные правила
Создаются автоматически для известных сайтов (Ozon, Wildberries, DNS, M.Video и др.).

## Подключение аккаунтов

**Настройки → Подключения → Добавить**

### Яндекс (Wordstat)
1. Нажать **Открыть Яндекс OAuth →**
2. Авторизоваться в Яндексе
3. Скопировать код подтверждения
4. Вставить в поле "Код подтверждения"
5. Нажать Добавить

### XMLRiver (SERP)
1. Ввести User ID (число с xmlriver.com)
2. Ввести API Key
3. Base URL: `http://xmlriver.com/search/xml`

Можно добавить несколько аккаунтов одного типа.
Кнопка **Тест** проверяет подключение.

## Запуск очередей

Для обработки задач сбора данных нужен запущенный worker:

```bash
# Все очереди
php artisan queue:work --queue=serp-scrape,wordstat

# Только SERP
php artisan queue:work --queue=serp-scrape

# Только Wordstat
php artisan queue:work --queue=wordstat
```

### Production
Используйте Supervisor или Laravel Horizon:
```bash
php artisan horizon
```

### Планировщик (cron)
Добавить в crontab:
```
* * * * * cd /path/to/serp-panel && php artisan schedule:run >> /dev/null 2>&1
```

## Типичный сценарий использования

1. **Зарегистрироваться** → создаётся организация
2. **Создать проект** (МойМагазин.ру)
3. **Добавить домены**: свой (myshop.ru) + конкуренты (ozon.ru, wildberries.ru)
4. **Создать категории и кластеры** (Электроника → Смартфоны, Ноутбуки)
5. **Импортировать ключевики**: CSV или вручную, выбрать Google+Яндекс, Desktop, регионы
6. **Настроить парсер**: XMLRiver с user/key
7. **Создать расписание**: проект + парсер + ежедневно
8. **Запустить** сбор → данные появятся в таблице мониторинга
9. **Настроить Wordstat**: подключить Яндекс OAuth → создать расписание Wordstat
10. **Мониторить**: фильтры, группировки, пресеты, экспорт CSV
